Step actions

Step actions represent the actions that can be performed during a simulation step, such as the enforcement of boundary conditions, the application of external forces.

A load is an EdelweissFE load (LoadBase): it assembles its own residual contribution, the negative of the external load it applies, and the tangent of that contribution in assembleLoad(P, K, U_np, dU, timeStep, locations), wherever it acts – on the cells of the background grid, on the cells of the material points that carry it, or on the faces of particles. A solver therefore only loops over the loads. The loads here derive from one of three bases, which implement assembleLoad once for all loads of their kind: MPMBodyLoadBase, MPMDistributedLoadBase and ParticleDistributedLoadBase.

assembleLoad(P, K, U_np, dU, timeStep, locations)[source]

Let every active cell of the cell set add the residual contribution of the body load, the negative of the external load, and its tangent; see assembleLoad().

The active cells are those of the discrete system, i.e. those the locations hold; a body load acts only on them.

Parameters:

  • P (DofVector) – The global residual contribution vector to augment.

  • K – The system matrix to augment, which hands out the block of a cell by K[cell]; None for an explicit solver, which needs no tangent.

  • U_np (DofVector) – The current global solution.

  • dU (DofVector) – The global solution increment.

  • timeStep (TimeStep) – The current time step.

  • locations (DofLocations) – The locations of the entities in the discrete system, from which the load finds where it acts.

Dirichlet boundary conditions

A Dirichlet boundary condition on the nodes of a node set is EdelweissFE’s StepAction, constructed from Python with the node set, the field and the prescribed components. A solver prescribes the nodes of the set that lie in the active domain (see locateFieldOnNodeSet()).

ParticleNitscheDirichlet class

A weak Dirichlet boundary condition by Nitsche’s method, which the particles integrate over their faces like a distributed load.

class edelweissmeshfree.stepactions.particlenitschedirichlet.ParticleNitscheDirichlet(name, model, journal, particleSurface, prescribedComponents, beta, dimension=2, f_t=None)[source]

Weak Dirichlet boundary condition via (non-symmetric/incomplete) Nitsche’s method.

Enforces prescribed displacement components on a particle boundary surface through the particle’s ‘nitschedirichlet’ distributed-load type, which assembles

  • the CONSISTENCY term -int_Gamma T . mask o ((S_dev + p I) DeltaF^-T (N dA)_Y) (the boundary traction the weak form drops under weak Dirichlet enforcement), and

  • the PENALTY term +int_Gamma beta T mask o (u - g) dA

directly into the momentum residual – no Lagrange multipliers or mortar fields are needed, and the boundary traction is smooth by construction (no point-collocation checkerboard). The adjoint (symmetry) term is omitted (theta = 0).

Unlike ParticleDistributedLoad, only the prescribed value g is ramped by the step amplitude; the component mask and the penalty parameter beta are constant. The load vector handed to the particle is [ mask (nDim) | g(t) (nDim) | beta ].

Parameters:

  • name (str) – Name of the boundary condition.

  • model (MPMModel) – The MPM model tree.

  • journal (Journal) – The journal to write messages to.

  • particleSurface (EntityBasedSurface) – The surface (faceID -> particles) on which the condition acts.

  • prescribedComponents (dict[int, float]) – Mapping component index -> prescribed TOTAL value at step end, e.g. {0: 0.0, 1: 5.0}. Components not listed remain traction-free (natural condition).

  • beta (float) – Nitsche penalty parameter (force / area / displacement). A good scale in the nearly incompressible regime is O(10) * K / h.

  • dimension (int) – Spatial dimension (default 2).

  • f_t – Amplitude function of the prescribed value over step progress (default linear).

Attributes:
loadType

The type of the load, one the particles support (e.g., pressure).

reactionForce

Total force transmitted through the constrained surface: the sum of the assembled Nitsche boundary forces (consistency + penalty) over all nodes, evaluated at the current particle state (call after the increment converged).
