class edelweissmeshfree.meshfree.approximations.base.basemeshfreeapproximation.BaseMeshfreeApproximation[source]

Base class for meshfree approximations.

In meshfree methods (MLS, RKPM), based on a finite number of kernel (RKPM) or weight (MLS) functions, an approximations can be computed at any point in the domain. This class provides the interface for the computation of such approximations.

abstract property hasBoxSupport: bool

Whether the support of the kernel function is exactly its axis-aligned bounding box.

For such kernel functions a coordinate lies in the support if and only if it lies strictly inside the bounding box, which lets callers replace a per-candidate support query by a vectorised box test. Kernel functions whose support is a subset of their bounding box (a sphere, for instance) must return False.

Marmot wrappers

Limit on the condition of the moment matrix

A particle that is stretched far beyond its neighbours – torn, with its damage close to one – can reach with a face into a void, a borehole or a crack, where only the kernels of one wall of particles cover it. These kernels lie nearly in one plane, on one side of the point, and reproducing a linear field there takes shape functions of the size of the distance to the wall over the scatter of the kernel centres about it. The particle’s smoothed gradients and its stiffness grow with them, and its critical time step in an explicit analysis falls: one such particle can set the time increment of the whole model.

MarmotMeshfreeApproximationWrapper takes the optional keyword argument momentMatrixConditionLimit: the completeness order of a point whose moment matrix (scaled to a unit diagonal) has a larger condition number is lowered, for the linear basis to the order 0, the Shepard functions, which stay between 0 and 1. With implicit gradients ("ReproducingKernelImplicitGradient"), such a point gets the gradients of the Shepard functions. The default inf sets no limit. With a limit, every point below it is evaluated bit for bit as without one, so an intact model is unchanged; a limit between 1e5 and 1e6 separates the points of intact particles from those of a torn one for the usual supports. The lower order has a price where it acts: the shape functions jump when a point crosses the limit, and a particle with such points no longer passes the patch test. See Marmot’s documentation of the meshfree approximation for the measure, the values it takes, and these costs. The limit acts on the shape functions, not on the material: a torn particle keeps its mass and its stiffness, it is not eroded.

approximation = MarmotMeshfreeApproximationWrapper(
    "ReproducingKernel", 3, completenessOrder=1, momentMatrixConditionLimit=1e5
)
class edelweissmeshfree.meshfree.approximations.marmot.marmotmeshfreeapproximation.MarmotMeshfreeApproximationWrapper

A meshfree approximation of Marmot: the reproducing kernel approximation with explicit gradients ("ReproducingKernel") or with implicit gradients ("ReproducingKernelImplicitGradient").

Parameters:

  • approximationType – "ReproducingKernel" or "ReproducingKernelImplicitGradient".

  • dim – The spatial dimension.

  • completenessOrder – The order of the polynomials the shape functions reproduce (keyword, required).

  • momentMatrixConditionLimit – The limit on the condition of the moment matrix, scaled to a unit diagonal, above which the completeness order of a point is lowered, for the linear basis to the order 0, the Shepard functions (keyword, optional). Such a point lies on one side of all kernels that cover it, which lie nearly in one plane: e.g. a point of a strongly stretched particle reaching into a void. There the linear shape functions extrapolate and grow without bound. The default inf sets no limit; with a limit, every point below it is evaluated bit for bit as without one. See Marmot’s documentation of the meshfree approximation for the condition measure, what the lower order costs, and the range of useful limits.

Integration helpers

Particle-Kernel-Domains describe the potential interaction between a set of particles and a set of kernel kernel functions. In meshfree methods, particles may convect through the spatial domain, and in general they may interact with different kernel functions at different times. For certain simulations, not all particles should interact with all kernel functions.

Hence, we designate possible interactions between particles and kernel functions by the ParticleKernelDomain class.

Variationally Consistent Integration is a concept by Chen, Hillman and Ruter (2013) to ensure Galerkin exactness of meshfree methods by employing a Petrov-Galerkin formulation.

It requires the computation of a set of correction terms, depending on the desired order of Galerkin exactness.

The implementation, albeit trivial in concept, does not readily fit into the existing workflow of nonlinear simulations: Before computing the weak form, the correction terms need to be computed, and the weak form needs to be adjusted accordingly. The correction cannot be computed locally (i.e., for each particle during the weak form computation), as it requires global volume and boundary integrals.
