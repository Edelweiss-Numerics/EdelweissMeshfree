Solvers

EdelweissFE’s implicit solvers

An MPMModel answers what EdelweissFE’s implicit solvers ask a model (see the models), so NIST, NISTParallel and NISTPArcLength solve it as they solve a finite element model, built from Python as any EdelweissFE step; see Choosing a solver. Their convergence criterion with the settings of EdelweissMeshfree’s former solvers is a parameter set of EdelweissFE’s legacy criterion:

The convergence criterion of EdelweissMeshfree’s (deprecated) implicit solvers, as a parameter set of EdelweissFE’s legacy criterion (see edelweissfe.solvers.base.convergencecriteria), for EdelweissFE’s implicit solvers NIST, NISTParallel and NISTPArcLength, which solve an MPMModel as they solve a finite element model.

A solver built from Python takes the tolerances per field from its jobInfo and the remaining parameters as options:

jobInfo = jobInfoWithMeshfreeTolerances()
solver = NISTParallel(jobInfo, journal, linsolver="pardiso", **meshfreeCriterionOptions)

Deprecated implicit solvers

The implicit solvers EdelweissMeshfree had before EdelweissFE’s implicit solvers solved its models.

Deprecated since version An: MPMModel is solved by EdelweissFE’s implicit static solvers NIST, NISTParallel and NISTPArcLength; see the documentation page Choosing a solver.

This package keeps the old solvers, so that the examples which still use them keep working:

  • NonlinearQuasistaticSolver (replaced by NIST and NISTParallel),

  • NonlinearQuasistaticMarmotArcLengthSolver (replaced by NISTPArcLength),

  • their common base implicitbase, and the predictors they take (predictors; EdelweissFE’s solvers have the option extrapolation).

They are frozen: they get no new features, only the adaptations that later changes of the interfaces they call force. Constructing one emits a DeprecationWarning that names its replacement. The package is deleted once no example needs it any more.

Predictors

The predictors make the initial guess of the Newton-Raphson scheme of the deprecated solvers.

Extrapolators (Predictors) are used for making initia guesses in the Newton scheme.
